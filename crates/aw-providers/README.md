# aw-providers

Optional HTTP/configuration integration for aw-agent-core. Includes native Ollama NDJSON and OpenAI-compatible Chat Completions SSE, explicit profile/endpoint/account selection, bounded framing, withheld raw provider errors, and lazy HTTP-client construction. No automatic model discovery, retries, redirects, proxy environment use, credential sharing or ChatGPT subscription login.

Consumers can omit this crate and implement the SDK Provider trait themselves. See [SDK guide](../../.agents/docs/SDK.md), [configuration example](../../examples/config.toml), and [build status](../../.agents/docs/BUILD-STATUS.md). Actual provider compatibility and compilation remain host validation gates.

## R3a native Anthropic Messages (2026-10-09)

The `anthropic` built-in profile selects `https://api.anthropic.com/v1/messages`, with `ANTHROPIC_API_KEY` as a *reference* read at admitted execution. SSE tool_use blocks, tool_result grouping, native effort and signed thinking continuity are handled by `provider/anthropic.rs`. Continuation is scoped to matching model/endpoint and kept out of durable/public transcripts, not an implicit cross-provider or cross-restart capability. The live `HttpProvider` pins the digest of the selected environment API key; if the key rotates, explicitly create a new provider/Session context. Full builds can select the versioned SecretStore account instead. The first-run wizard offers Claude API (not consumer-subscription sign-in). Other model-specific Anthropic features and manual thinking budgets remain unimplemented; see [accepted history](../../.agents/plans/accepted-history/TODO.md).

## R3b native Gemini GenerateContent (2026-10-09)

The built-in gemini profile uses Google AI Studio GEMINI_API_KEY and the native streamGenerateContent SSE protocol under the configured `/v1beta` API root. The model ID is validated as a single URL segment; x-goog-api-key is the only key transport (no Bearer or query parameter). The same explicit SecretStore custody works in full builds. Provider-specific `gemini.rs` maps tool calls/results, thinking levels where their meanings are known, and preserves exact thoughtSignature-bearing provider parts in transient in-memory context only. Ordinary Session persistence never exports signatures. Model/tool schemas use Google’s documented parametersJsonSchema field instead of silently discarding host-side validation constraints; arbitrary live schema compatibility is still to be tested. Google Interactions, Vertex and multimodal support remain separate, as do full model pricing/discovery caches. Scope: [accepted history](../../.agents/plans/accepted-history/TODO.md).

## R4 shared model metadata catalog (2026-10-09)

aw-providers::catalog is the one source for bounded explicit model discovery, offline reference/configured IDs, optional provider-reported model capabilities/context/output limits, and private per-account 24-hour discovery cache. The default std hosted build uses reqwest and aw-platform private 0600 atomic XDG cache files; neither the no_std embedded kernel nor the primary Agent loop loads this catalog directly. The first-run chooser and aw model CLI consume this source; model discovery never issues account/tool grants or chooses a new payer. Anthropic and Gemini cursors are bounded, cyclic/error pages fail without partial cache commit, and unknown context/prices remain unknown. User-supplied rates are separate exact integer microUSD-per-MTok overrides and cost estimates are not invoices. Bundled reference IDs are dated, informational, and only shown for exact official endpoints. Data-only OpenRouter/xAI/DeepSeek/Groq/Mistral/Together OpenAI-compatible presets require explicit provider selection and API key references.
