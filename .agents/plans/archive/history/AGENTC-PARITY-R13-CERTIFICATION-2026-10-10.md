## Architecture and scope

R13 provides an independently executable local **certification framework**, not a rewritten Agent or self-declared total parity sign-off. True full agentc 0.6.0 parity requires executing the original agentc reference executable and checking equivalent concrete paths; it is NOT available on this host. Cross-platform runtime certification requires the actual binary executing on that platform, not cross-compiled ELF/Mach-O/PE headers, source manifests, CI configuration or release checksums. Linux host uses installed Rust 1.95.0, not pinned 1.98.1; QEMU ARM64/RISC-V emulators are unavailable. No native OS-free ELF firmware or audited C ABI is available. Failing/unknown requirements are reported OPEN, never certified by inference.
