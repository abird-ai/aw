## 1. Strict authorization and Process binding

1. **The model can request exactly one new operation:** `process_terminate` with JSON `{"op":"terminate","handle":"opaque_original_owned"}`. It is a separately declared original `ToolEffect::Write`, *not* process-close, D1 Read, Process spawn, arbitrary signal, kill PID, stdin content, PTY, OS freezer, child Agent cancellation, or a human approval. The JSON validator rejects all additional keys including `pid`, `program`, `writer_epoch`, `ActorKey`, `ToolPolicy` grants, `stdin`, signals, environment and Process OS root. Handle is a bounded 1–64-byte opaque identifier with restricted printable ASCII. No OS PID/command/stdin/stdout/stderr is ever included in the model ToolOutput.
2. **Explicit original owning HOST enrollment and TWO independent permissions:** Only a trusted current local Host can call `aw::model_process_control::install_terminate(&Service,&mut Agent,ProcessRegistry)` with its same current authenticated original `actor_owner::Service` and original journaled Agent; this is **OFF by default** for normal CLI/R12/TUI/web/MCP/signed AwNet/QUIC. It MUST already have exact current Actor `Envelope` **Host/trusted-host/epoch1/Write** permission specifically named **`process_terminate`**. The same original `Agent::register_host_tool` grants matching original ToolPolicy Host/Write source/effect/site permissions only after that precheck. An independent D1 `process` Read, 9D2B2A `process_close_stdin` Write, queue Write or a model/plugin/tool-name cannot authorize this more destructive effect. Original Agent advertises and executes only through original ToolPolicy/AgentStepGate, with mandatory current owner/WriterEpoch/Actor generation/Session+branch/execution site/payer+credential/active immutable `actor.input Dispatching` and actual live Runtime Turn/cancellation checks **before** and **after** each effect.
3. **Separate per-Process current host authorization:** `ProcessRegistry::register_owned` remains observation/ststdin-close only and is **NOT TERMINABLE**. New explicitly named **`register_terminable_owned`** is trusted-host-only and accepts one already independently allowed/spawned/journaled original `aw-tools::process::PipeProcess` (max16 same owner/Session/branch/site/writer epoch), mints a **random 32-byte OS-entropy registration incarnation** (private 64-character hex) and binds it to the live original Process Arc. Only `ProcessRegistry::resolve_terminable`, crate-private to the original local Host SDK, can retrieve that exact handle and immutable private incarnation. Model-provided handle never supplies authority to choose a PID or rebind another Process. This registration is an affirmative host policy decision; the SDK cannot independently prove that a dishonest host actually authorized and journaled the earlier Process spawn. No Process is created by tool registration.
4. **Prior durable original owner and Process intent are mandatory:** `Service::prepare_model_process_terminate` reuses the original D2B2A **domain-separated one-intent-per-originating-Session+branch+Turn `mp_` SHA256** ID. Its payload now has typed `ModelProcessAction::Terminate` plus a private original-host-minted **`process_binding`**, required to be exactly 64 hex bytes for termination. Original CloseStdin facts omit that field via backward-compatible `serde(default, skip_serializing_if = String::is_empty)`; there is **no SQLite migration or legacy adapter** and old Action `CloseStdin` semantics are preserved. The original SessionStore's SQLite **v33 `actor.model.process` `BEGIN IMMEDIATE`** verifies current Session owner/writer, selected branch and actual `runs.status='running'` + immutable original `actor.input Dispatching` with exact sender/target/Turn/writer, and appends **Prepared** BEFORE any signal. A single original Turn may do **at most ONE** Process effect across `process_close_stdin` and `process_terminate`, no matter how many ToolCalls, target handles or names the provider proposes. A Prepared/Unknown/Inspected earlier receipt blocks every retry permanently.
5. **Original bounded OS teardown—not arbitrary OS control:** The host obtains the existing Process mutex with a **non-blocking `try_lock`** and verifies the original direct child is still running and has **never received a termination attempt**; observation-only registration, unknown/revoked/foreign handles, busy, already exited or already-terminated Process deny BEFORE Prepared. Only then it commits immutable Prepared, rechecks original current owner/ToolContext, and calls the new bounded original `aw_tools::process::PipeProcess::terminate()`. It reuses the ORIGINAL pre-existing `stop()` group cleanup (short graceful request, bounded forced-kill fallback/reap and capped stdout/stderr drain), without adding a kill-by-PID API. The original Process now carries an irreversible in-memory **`termination_attempted`** guard set **before the first OS signal**; a second call to terminate is refused even if the first attempt or output drain was uncertain. Existing original Process `wait` cancellation uses the same guard safely; no second process runner or new OS resource is introduced. A successful native Tool requires the existing original Process `Outcome::Cancelled` **and** completely drained output; if not, original host appends `ModelProcessState::Unknown` and the Tool fails requiring inspection. It never auto-retries. These low-level process-group calls are original platform-specific best-effort cleanup; this Linux test is NOT cross-Windows/macOS/ARM process isolation or PID-reuse/pidfd certification.
6. **Terminal receipts cannot be fabricated after crash:** Only the SAME pinned current original owner **process ID/store generation incarnation** may use `SessionStore::model_process_transition(Prepared -> Applied/Rejected/Unknown)` under the current original SQLite writer. `Applied` means only **the bounded original termination attempt returned Cancelled and drained direct child stdout/stderr**, NOT that arbitrary descendant processes or an external paid provider/service settled. Duplicate model Write proposals may leave one Applied direct-child termination fact but the ORIGINAL paid/Tool Turn must remain **Unknown/needs-inspection** rather than falsely complete or replay another model/provider turn.
7. **No model-origin human or Agent control:** `agent.cancel`, self-freeze, child Actor mutation, arbitrary Process stdin writes/signals/PTY/graceful OS destructor, and `review.approve` remain **OFF and unimplemented**.
