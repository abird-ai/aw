# V1.2 — Header Space/Machine context switching

Status: HISTORICAL UX concept. Interactive preview: [v1.2.html](v1.2.html).

## Design improvement

Space and machine navigation are frequent context actions, not persistent sidebar inventory. Move them to a unified header:

    aw / abird ▾ / aw ◆ main                    ● x2 ● a1 ▾

- Click Space name: full Spaces management tab.
- Click adjacent Space chevron: quick switch named and Local Spaces.
- Click machine names/indicators: full Machine/Fleet management tab.
- Click machine chevron: open a selected machine's **Local Space**.
- Switch restores its previous visual context without moving active Agent processes or granting access to that destination.

## Unified Space model

A machine has one non-deletable built-in Local Space. Local Space opens into Home (~) as a working context, **not a fake Git project**. Repositories are discovered only on actual navigation/registration.

A user-created Space can contain one machine or several. Attaching a second machine makes it a fleet Space, without changing its identity. Machine membership never automatically merges Git worktrees, files, provider keys, process capabilities or OS accounts.

    Space ▾                             Machine ▾
    ┌───────────────────────┐           ┌───────────────────────┐
    │ ✓ abird · fleet x2+a1 │           │ ● x2 → Local · x2    │
    │   Local · x2 · Home ~  │           │ ● a1 → Local · a1    │
    │   Local · a1 · Home ~  │           │ Manage fleet →       │
    │ Manage Spaces →       │           └───────────────────────┘
    └───────────────────────┘

## Full tabs

Spaces: create/rename/delete named Spaces with intentional safeguards, associate projects and exact worktrees, manage membership.

Machines/Fleet: connect/pair/remove, inspect link freshness, trust and runtime capability, attach/detach from Space, inspect PTY/session ownership. Disconnected last-known data stays visible but stale and cannot silently accept unsafe input.

## Relationship to V1.3 and V1.4

The V1.2 screenshot focused on demonstrating header switchers and temporarily reduced the main Workspace. V1.3 deliberately restores the **full terminal-shaped Agent/Diff/PT Y tile presentation** while retaining this exact header model.
