# V1.1 — Quiet Recents and background/autonomous Activity

Status: HISTORICAL UX concept. Interactive preview: [v1.1.html](v1.1.html).

## Key decision

Maintain the three Pi-like/native Agent/Workspace modes of V0 and V1, but emphasize where the user has recently worked and where attention is needed.

- Recents: the last three **intentional visits**, at most two in compact presentation. Destination types include Workspace layouts/tabs, Agents, Projects, exact Worktrees, Files and PTYs; completion/polling does not change Recents order.
- Projects: primary repository/worktree tree with selected project expanded and others collapsed.
- Activity shelf: one compact overview of **Now** (live and delegated background Agents), attention and Automations. A background Agent is the same Agent identity as a foreground one. An automation is a trigger definition, not another running Agent.
- Agent status, per-client unread notifications, machine connectivity and Git dirtiness are distinct fields. Do not collapse them into one color or duplicate an approval in multiple lists.

    Now                     3
      ● coordinator
        ├─ ● runtime · bg
        └─ ◐ hooks · bg
    Automations              2
      ↻ dependency updater · Git trigger
      ◷ nightly checks · daily schedule

The expanded Activity pane can show Agent lineage, machine, true owner, active operation, exact worktree, unread state and policy/approval facts. The default shelf should remain quiet. Successful completions update status/unread, not popups or automatic focus changes.

## Evolution

V1.2 moves Space and Machine switching to the header; V1.3 combines Recents with the Activity hierarchy and the Projects/Recents navigator; V1.4 makes the upper tabs tiny icons, adding compact Git/Files mini docks.
