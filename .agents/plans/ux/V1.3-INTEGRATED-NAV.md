# V1.3 — Integrated Projects/Recents and Activity

Status: HISTORICAL UX design, [v1.3.html](v1.3.html).

## Organize around destinations and activity

V1.2 Space/Machine header stays; V1 Review tiles and full PTY/Git/Files remain first class. Sidebar contains **Projects | Recents** as two textual tabs, switching one content area instead of duplicating both at once.

Projects: actual repository/worktree tree with machine context. Recents: full flat history of intentional destination visits, including Agent, project, worktree, file, terminal and Workspace layout.

The compact Activity area contains only **Recents (top 3)**, **Now (live and background Agents)**, and **Automations (definitions)**. One branch expanded by default; opening full Recents auto-collapses the mini Recents branch to avoid duplication. A single amber attention count jumps to the real nested Agent/approval, without a permanent duplicate Needs You list.

V1.3 retains V0's minimal conversation; Agents mode favors Activity Now. Work remains on one original Agent/TurnMachine and its factual journal. Switching sidebar views must not re-own a process or retarget an effect.

## Limitation resolved by V1.4

Textual upper tabs consume room, and users still want Git and Files at a glance while reviewing Agent work. V1.4 introduces icon-only upper navigator + independent lower Activity/Git/Files dock with movable divider.
