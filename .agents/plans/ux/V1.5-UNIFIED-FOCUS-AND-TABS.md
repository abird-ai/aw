# V1.5 — Canonical unified Workspace and focused panes

**Status: CURRENT UX DESIGN**, following the preserved [V1.4](V1.4-CANONICAL.md). All information here is DESIGN ONLY, not a production runtime claim. Explore [V1.5 HTML](v1.5.html) or the [universal switcher](index.html), and the screenshots in [VISUAL-GALLERY.md](VISUAL-GALLERY.md).

**Thesis:** Two presentation modes—Minimal and Workspace. The old third Agents mode is simply Workspace with a native Agent pane maximized. Any file or diff may be previewed within the existing Files/Git container, opened as a standalone tab, or maximized in its current container.

## 1. Two modes instead of three

| Mode | What is visible | What stays |
| --- | --- | --- |
| **Minimal** | Pi-like native Agent transcript, understated tool results, composer and **bottom status only** | Same Session/Agent/context; no top header, sidebar, tab bar or permanent inspector |
| **Workspace** | Global Space/Machine header, upper Projects/Recents mini nav, lower Activity/Git/Files mini dock, composable saved tab layouts | Same actual Agent, tool grants, Git worktrees and PTYs; no duplicated execution engine |

**Important:** switching modes never starts/stops Agents, moves machines, changes credentials, or drops scroll positions. F2 / equivalent may toggle Minimal ↔ Workspace, with terminal key collision audit still required. The previous Agents mode remains only in the archived V0–V1.4 previews. Selecting an Agent in V1.5 opens/focuses the Workspace Agent tab; maximizing it provides the earlier Agents-mode main-content presentation.

The default Review tab contains Agent + Diff + Test PTY, retaining V1.4's full developer Workspace. All panes, including Agent, Diff, File explorer/editor, Git changes list, Git diff and each real PTY, show a **small maximize/restore control in their own pane header**. Zoom hides sibling panes inside the current tab; restoring reinstates original split ratios, scroll positions and focus. A single-pane standalone File/Diff tab can use distraction-free immersive zoom to hide Workspace chrome while keeping Restore available.

A Workspace tab is a saved layout or a referenced File/Diff viewer, **not another Agent Session or process**. Closing a tab merely hides its view; it never kills a PTY, stops an Agent or reverts changes.

## 3. File and Diff flow — three distinct actions

| Action | Effect | Does NOT |
| --- | --- | --- |
| **Preview** (select in contained Files/Git tab) | Change that tab's right-hand contained File/Diff viewer | Create a tab, stage, write, or change current Agent |
| **Break out** (small ↗ next to contained viewer) | Create/focus a standalone File or Diff tab | Replace or close original Files/Git tab |
| **Maximize** (small ⛶ / ❐ next to any pane) | Temporarily show that pane alone, then restore original arrangement | Create tab, change selected source, execute anything |

### Files tab remains a contained workspace

    [Files]
    ┌─ Explorer           ⛶ ┬─ tool.rs · preview       ↗ ⛶ ┐
    │ ▾ crates             │ 71 pub fn authorize(..) {     │
    │   ▾ aw-agent-core    │ 72    let source = ...        │
    │     M tool.rs        │                              │
    └──────────────────────┴──────────────────────────────┘

A file selected inside this Files tree previews in its existing editor, without creating a tab. Clicking ↗ breaks that selected file out into an independent File tab while keeping Files' selected tree and layout. Clicking ⛶ instead maximizes only the contained editor, hiding the tree until restore. Selecting from **mini Files**, Recents, command palette or global Quick Switch can open the same file directly as an independent tab, without first navigating to the full Files container.

### Git and diffs work symmetrically

The Git tab contains Staged/Unstaged changes and its own contained Diff preview. Selecting a changed file previews its Diff only; ↗ opens a standalone Diff tab; ⛶ maximizes the contained diff. Selecting from mini Git or global Quick Switch opens an independent Diff tab directly. Stage/revert/commit remain explicitly authorized commands, never triggered by selection, opening or maximizing.

A standalone File tab and a standalone Diff tab are different presentations and may coexist for the same path.

## 4. Exact identity, tab deduplication and close behavior

Standalone File tab identity must include **Machine/Site + WorktreeRef + FileRef**. Standalone Diff tabs additionally include diff scope (staged/unstaged/commit/base/revision). Tabs are deduplicated by those opaque, canonical references; never by filename alone. Two files named tool.rs on different hosts remain distinct.

Opening an already present tab focuses it; no redundant editor buffers, runtime Agents, model loops, or Git scanners. Break-out remembers its **originating tab** for predictable close: closing a Diff opened from Review returns to Review; closing a File opened from Files returns to Files. Opening from mini dock or palette remembers its current origin likewise. Closing tabs never mutates file/repo content or Session state.

Files/Git keep their contained cursor, tree expansion, previewed file/diff, scroll, and split ratios independently of the open standalone tabs. Maximization is **tab-local** and reversible. For single-pane standalone tabs, immersive maximize may hide the Workspace sidebar/tab strip while keeping Restore accessible in the pane head.

## 5. Agent and PTY are just other pane contents

The removed Agents mode becomes a native Agent tab whose pane may be maximized (sidebar remains available, so nested Agent selection still works via Activity → Now). A delegated child is a distinct Actor/Session with real parent relation, not an independent visual mode or a duplicate listing. Selecting a child focuses or opens its existing Agent viewer; background state is separate metadata.

Each real PTY tile has exactly the same ⛶/❐ controls. Zoom and new tabs **cannot steal terminal input/resize ownership**. Machine connection and viewer/owner badges are independently visible; stale disconnected sessions remain read-only until reattached. Pane focus, selected item and effectful input rights are three separate notions.

## 6. Carry forward V1.4 navigation exactly

- Space name opens full Spaces tab; ▾ quick-switches named/Local Spaces.
- Machine indicators open Fleet tab; ▾ switches to the machine's Local Space (Home ~, not a fictitious Git repository).
- Upper sidebar: icon-only Projects ▦ / Recents ◷.
- Lower independent resizable icon dock: Activity ● / Mini Git ± / Mini Files ▤; remains read-only on row selection.
- Activity: Recents top three, Now true Agent hierarchy, Automations definitions; only one expansion default, suppress duplicate mini Recents when upper full Recents active.
- Per-client unread completion, attention, running, Git dirty and connection health are distinct signals. Small colored status glyphs always have meaningful text/shape fallbacks.

## 7. Keyboard / mouse design and focus

- Small pane-header ⛶ maximizes; ❐ restores. A double-click on a pane header may toggle maximize; don't steal editor/terminal clicks.
- ↗ on contained File/Diff opens separate tab; standalone tabs show small × close button, focusable separately from tab selection.
- Ctrl+P (where available) quick-switches among typed destinations including Files, Diffs and Agents. A palette File or Diff result opens its own tab.
- F2 / configured equivalent toggles Minimal ↔ Workspace; no third mode. Existing keyboard ownership of a real PTY overrides global shortcuts except a configured leader. Ctrl+Shift+P should retain aw's command palette.
- Keyboard Enter on a file tree previews within its **contained** Files tab; explicit alternate action opens as standalone tab. Keyboard Escape in a real PTY belongs to that PTY.
- No sidebar, tab, file or Agent selection can unexpectedly change the true editor/PTY input owner.
- Zoom/restoration and narrowing the physical terminal cannot lose the split tree or its scroll anchor.

10. Standalone File/Diff ⛶ enters immersive focus, ❐ restores Workspace UI with same file/diff.
11. Terminal grid has per-PTY maximize; no fake execution or input takeover.
12. Switching modes/tabs never discards real Agent, PTY, journal or worktree.
13. **Historic V0–V1.4 prototypes and checks stay independently accessible and unchanged.**

## V1.5 polish — one document title, one native aw command palette

**Current V1.5 refinement, overriding earlier duplicate-header and Ctrl+P suggestions.** All historical V0–V1.4 designs are preserved; this remains UX-only.

### A. No more redundant headers

The global Workspace header says WHICH Space/machines. The saved tab name says WHAT document/layout. Only a SPLIT pane needs its own short title to distinguish it from sibling panes.

| Presentation | Keep | Remove |
| --- | --- | --- |
| Workspace Review | Space/machine header, Review tab, one name per Agent/Diff/PTY split pane | Generic second Review/branch title bar |
| Contained Files | Files tab, Explorer pane label, one filename on editor pane, small breakout and zoom actions | Second file-path/title line inside the code |
| Contained Files editor maximized | Files tab, one editor header with filename and restore | Duplicate context/title bar, temporarily hidden explorer |
| Contained Git | Git tab, Changes pane and concise Diff · filename pane title | Generic second Git/branch title row |
| Contained Git Diff maximized | Git tab, one Diff filename header and restore | Duplicate Diff heading in body, temporarily hidden list |
| Standalone File tab | Tab label with file name and close, ONE subtle worktree/site context line, floating maximize | Second File/filename pane title |
| Standalone Diff tab | Tab label with diff filename and close, ONE subtle diff-scope/worktree line, floating maximize | Second Diff/filename pane title |
| Immersive standalone File/Diff | Minimal floating filename and restore; content starts immediately below | Space/machine header, tab strip, sidebar, nested title bar |
| Minimal Agent | Native conversation, composer, one bottom status | Entire top header, sidebar and tabs |

One title has one owner. When a standalone tab already names the file, the viewer does not repeat that filename. When immersive zoom hides the tab bar, a tiny contextual filename plus Restore replaces its identity, instead of adding another full-width title. Actual worktree, site and read-only/diff status still remain discoverable. The maximize and breakout controls are small and keyboard accessible.

### B. Extend the EXISTING aw Command Palette, not a second quick switch

The current Rust palette implementation (read-only verified in src/workspace/palette.rs) has six canonical categories and these exact one-character prefixes:

| Prefix | Existing category | UX use |
| --- | --- | --- |
| > | Actions | Create visual tab, maximize pane, open Spaces/Fleet |
| ! | Windows | Saved Workspace tabs/windows/layouts |
| @ | Files | Open standalone File or scoped Diff result |
| # | Sessions | Durable conversation/session references, distinct from Agents |
| $ | Terminals | Existing PTY on an exact machine, with viewer/owner state |
| / | Commands | Existing slash commands such as /think and /theme |
| & | **Agents (NEW PROPOSAL)** | Search real root/child/background Agent refs, status and owner/site; focus native Agent tab |

Windows really uses **!**, not %. Keep the slash Commands and Sessions categories distinct from Agent identity. The proposed & Agents category is the only new palette category; do not create a second global search/Quick Switch UI or new permission engine.

Follow the real aw invocation: **Ctrl+Shift+P or F1**. Ctrl+P remains input history or PTY input except where aw already supports a navigation-only fallback; the visual prototype must NOT globally steal Ctrl+P. Use one centered modal titled Command Palette, a single editable search line, subtle prefix/category chips, selected result and thin footer for arrows/Enter/Esc.

Filtering examples:

    > Open Spaces      -> Actions: Open Spaces management
    ! Review           -> Windows: saved Review tab
    @ tool              -> Files: tool.rs File and tool.rs Diff
    # aw/main           -> Sessions: current durable conversation
    $ tests             -> Terminals: existing test PTY on pvl-a1
    / think             -> Commands: existing Agent slash command
    & hooks             -> Agents: hooks lead · awaiting review · a1

Prefix changes preserve the query BODY as the current palette does. Results are typed destination refs, not display-name permissions; choosing File/Diff creates/focuses a visual tab only, choosing Agent focuses its existing Session, commands require the current command authorization semantics, and terminal viewer never gains writable input rights from selection.

### C. Acceptance additions

- V1.5 Workspace has no second generic context/title bar.
- Standalone File/Diff: one tab title; no inner pane title; context line has only new worktree/site/scope information.
- Immersive File/Diff still exposes a floating Restore and unobtrusive identity.
- Contained File/Git viewer when maximized has exactly one meaningful pane title.
- In both Minimal and Workspace, one aw palette opens with Ctrl+Shift+P/F1, and Esc dismisses without effect.
- Seven prefixes are **> ! @ # $ / &**, one-to-one, with & Agents added; ordinary Ctrl+P remains owned by composer/PTY.
- Category filters, keyboard arrows, Enter activation and File/Diff/Agent/Window/Session/Terminal choices route to the SAME typed presentation/actions.
- Old V0–V1.4 interactive screen behavior and visuals remain independently accessible.
