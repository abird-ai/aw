# V1.4 — CANONICAL aw TUI target

Status: CURRENT UX DESIGN to pursue (2026-10-11). Previous versions preserved as distinct historical references. [V1.4 live HTML](v1.4.html) · [All-version switcher](index.html).

## Product experience

Pi-like single-Agent conversation. Herdsman-like nested Agent ownership and status lights. Herdr-inspired truly composable panes with real external PTYs. A first-class native developer Workspace for Git, Files and Diffs across exact worktrees and many machines. Features under progressive disclosure; **quiet by default**.

## The three modes (one shared state)

1. Minimal Agent: no fixed sidebar, tabs or inspector; native structured transcript, tool output strips, Pi-style composer, compact status. Never replace native Agent with screen-scraped PTY.
2. Agents: compact sidebar with Activity → Now favored, true nested parent-child lineage, muted machine/project hints, approval indicators; full main transcript.
3. Workspace: composable named tabs/panes, optional right inspector hidden by default. Main Review preset: Agent + Diff side-by-side, real test PTY below. Full native Git, Files, PTY and management tabs always one action away. Still useful with ONE repo and ONE Agent.

## Header semantics

Top-left aw / Space / Project/Worktree. Space name opens full Spaces tab; adjacent ▾ opens Space quick switcher. Top-right connected machine names/icons open Fleet management, adjacent ▾ quick switches to that machine's Local Space. Each machine's built-in Local Space starts at user's Home (~), which is a directory context, never fake Git. Named Space with 2+ machines is a fleet automatically; membership never grants access or migrates running Agents.

## Upper sidebar (one view, tiny icons)

Left header shows 'projects' or 'recents'; right only [▦][◷] with selected indicator and keyboard tooltip.

- Projects: selected Space's real repositories/worktrees, Git branch/dirty glyphs, machine source; selected project expands, others collapsed. No source indexing requirement.
- Recents: full deduplicated *intentional navigation history*: visited Agents, tabs/layouts, terminals, files, projects, worktrees. Each entry shows small type glyph and muted scope, never updates from background token or tool events.
- A full Recents selection automatically collapses the redundant lower Activity/Recents subsection without forgetting its saved expansion state.

## Lower dock (one independent view, tiny icons)

Dock header left selected label ('activity', 'git', 'files') with optional one meaningful badge; right only [●][±][▤]. Defaults to ~40% of usable sidebar height, upper navigator ~60%. Mouse/keyboard resize; lower minimum 4 rows; one-line collapsed state still shows selected title and attention/dirty count.

- Activity: Recents (top 3), Now (true live Agent ancestry including background/unattached), Automations (definitions with current run links), one subgroup open by default. An Agent appears once in Now even if its origin is automated and it's executing in background. Attention count is shortcut/filter into true ownership; never a duplicate global Agent list. Per-client unread independent from outcome.
- Mini Git: current **exact Worktree** staged/unstaged tree and file status/line counts. Selecting a file opens/focuses the full Diff without staging. If Home/no Git, show 'No Git repository selected'. Source machine never omitted.
- Mini Files: lazy selected folder tree with changed-file markers. Select opens full file viewer/read-only preview. No implicit filesystem-indexing/LSP work.
- Upper/lower tabs can switch independently; no auto-switch of Agent, PTY or main Workspace due to background notifications.

## Full Workspace tabs

Review: Agent + Diff + test PTY. Agent: native transcript. Git: staged/unstaged changes, hunks, explicit stage/revert/commit. Files: lazy tree, line-numbered highlighted source, search. Build/Terminals: four true PTYs across selected scope, each owner/viewer/machine. Spaces/Fleet tabs: full connection/membership management. Saved tabs represent layout trees, NOT processes/Agents; closing a pane hides/detaches only, never silently terminates.

## Status and trust

Green ✓ confirmed successful/healthy; blue ● running/new activity; amber ◐ requires attention / M changed; red ! failed/blocked; gray ○ idle/unknown/stale. Always symbol+text. Only exact user-approved/host-authenticated Session actions can change execution rights. Machine disconnect retains last-known presentation, disables unsafe input, marks status stale. PTY viewer vs writer/resize owner separate. Source/git operations pin exact machine/repo/worktree. Unknown paid/model/tool effects never auto-replay.

## Responsive and accessibility

~160 columns: tiles, sidebar 28–34 columns; 110–159: narrower sidebar, optional secondary panes; 80–109: focus primary, lower dock may collapse; under 80: single pane with on-demand navigator. Never throw away pane state from resizing. Cursor/selection/focus must be independently visible. Unicode box/tree glyphs have ASCII fallbacks and 16/256/truecolor theme mapping; color is not sole status encoding.

## Acceptance criteria

- Single-Agent minimal feels like Pi and remains uncluttered.
- Agents mode shows true nested subagents; no redundant Background tree.
- Projects/Recents toggles upper sidebar, Activity/Git/Files toggles lower without changing main pane.
- Mini Git/Files operate on exact selected worktree/location and open correct full views with **no side effects on selection**.
- Activity Now and Recents are not duplicate lists; read/unread and attention are distinct.
- Header Space/Machine switches do not reroute ongoing work; Local Home not a Git project.
- True PTYs preserve focus, terminal escape sequences, scrollback, copy and owner semantics.
- Tight terminals collapse presentation only, preserving panes/sessions/scroll anchors.
- No uncontrolled approvals, grants, process starts or CLI behavior from a visual change.
