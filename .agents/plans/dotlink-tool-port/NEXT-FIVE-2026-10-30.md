# Shared toolset next five implementation phases (2026-10-30)

Author: @pvl
Co-authors: ChatGPT GPT-6

Read-only dotlink reference: ../dotlink (l5 connector). AW's original
Agent/ToolRegistry/ToolPolicy/TurnJournal and Session/Process owner remain
canonical. No changes to dotlink, reserved UX or shared plan index.

1. **TS-N1: task ownership contracts and admission hardening.**
   Strengthen bounded task/spool accounting, safe transitions and writer
   settlement under concurrent cancellation. Prove limits and invariants with
   deterministic tests. No second task database.
2. **TS-N2: integrate writer leases with AW's actual supervised Process.**
   Wrap original stdout/stderr reader tasks in shared RAII leases, seal before
   terminal publication, and establish writer-quiescence evidence. Preserve
   cancellation, outcome and journal-before-effect.
3. **TS-N3: bounded process result paging and ACK projection.**
   Provide read-only, exact byte-range pages from the existing bounded
   head/tail capture. Distinguish an unrecoverable middle gap from a complete
   spool; track delivery and acknowledgement monotonically. No unapproved
   background process/job tools.
4. **TS-N4: bounded native-media handoff contract.**
   Add transport-neutral verified media classification/size/digest contract.
   AW read tool may use it for safer encoded JSON; typed Provider/MCP
   ContentBlock remains unadvertised until explicitly supported.
5. **TS-N5: sandbox policy validation and portability closure.**
   Validate explicit host sandbox profiles without granting execution;
   exercise native Unix/Windows shared-tool compilation/tests and all-feature
   gates, reconcile the port accounting. No Bubblewrap launcher magically
   implied by a feature flag.

Phase acceptance: each phase has its own source tests and targeted validation;
the original-l5 Cargo.lock registry remains a known environment blocker, so
the isolated ignored target/review-tool-integration runner is used, with
unmodified AW source and platform/Agent crates. Do not claim full AW workspace
tests or native Windows runtime from this runner.
